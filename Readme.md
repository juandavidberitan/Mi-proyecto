# Sistema de Gestión de Eventos

## 📌 Descripción
Aplicación web para gestionar eventos, personas y encuentros. Desarrollada como proyecto universitario para demostrar habilidades en desarrollo backend, bases de datos relacionales y documentación técnica.

## 🛠️ Tecnologías utilizadas
- **Python** - Lógica de negocio
- **Flask** - Framework web
- **PostgreSQL** - Base de datos relacional
- **psycopg2** - Conector a PostgreSQL
- **HTML/CSS** - Interfaz básica

## 📊 Características
- Visualización de personas, eventos y encuentros
- Generación de datos de prueba (100 personas, 20 eventos, 200 encuentros)
- Interfaz web sencilla y funcional
- Documentación completa (diagramas UML, manual de usuario)

### Requisitos previos
